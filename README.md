# Сканер — Android-сканер пространства

Цель проекта — дать на обычном смартфоне приблизительную карту препятствий, а не выдавать акустические пики за точные координаты предметов.

## Архитектура измерений

### 1. Акустический канал (экспериментальный)
- Динамик передаёт короткий широкополосный chirp, микрофон записывает прямой сигнал и отражения.
- Расстояние вычисляется относительно найденного прямого сигнала по времени двойного пути.
- Эхо — это отражение звука, а не идентификация объекта. Один динамик и один микрофон телефона не дают надёжной угловой селекции: направление задаётся в основном ориентацией телефона.
- Встроенные динамики/микрофоны не калиброваны как измерительная пара. АЧХ, системная задержка, шумоподавление, чехол и акустика комнаты сильно влияют на результат.
- Поэтому акустические точки рисуются только при повторяемости, а карта хранит максимум один ближайший устойчивый возврат на угловой сектор. Отдельные поздние пики не считаются отдельными предметами.

### 2. Камера и движение
- Redmi Note 8 не указан Google как устройство с ARCore Depth API. Наличие дополнительной 2-МП камеры не означает наличие ToF-датчика глубины.
- ARCore Depth строит карту глубины по движению камеры, а при наличии аппаратного ToF может объединять его данные. Наилучшая точность обычно достигается примерно на 0,5–5 м; белые/однотонные поверхности могут давать неточную глубину.
- На данном устройстве нельзя обещать аппаратную карту глубины через ARCore. Обычная камера в сочетании с IMU может использоваться для визуального движения/распознавания, но без глубинного сенсора абсолютная дистанция и геометрия ограничены.

### 3. Инфракрасный канал
- Consumer IR (ИК-порт для пультов) — передатчик команд, не дальномер.
- Фронтальный датчик приближения — короткодействующий датчик «рядом/не рядом», не измеритель расстояния до стен на метры.
- Настоящий IR ToF, например ST VL53L1X, — отдельный модуль с VCSEL 940 нм и приёмной матрицей; он требует физического подключения по I²C и не может быть включён программно через ИК-порт телефона.

## Ограничения Redmi Note 8
- Нет подтверждённой поддержки ARCore Depth API.
- ИК-бластер не измеряет расстояние.
- Фронтальный proximity sensor рассчитан на близкое обнаружение.
- Акустический канал остаётся экспериментальным и не должен использоваться как средство безопасности или замена реальному дальномеру.

## План развития
1. Сократить ложные точки и отображать только повторяемые ближайшие возвраты.
2. Добавить журнал измерений и оценку качества сигнала, чтобы калибровать пороги на реальном телефоне.
3. Разделить визуальное распознавание предметов и измерение дистанции: классификатор камеры не должен сам придумывать расстояние.
4. При подключении внешнего ToF/ультразвукового модуля добавить отдельный аппаратный профиль дальномера.
5. Проверять дистанции на размеченных реальных целях и хранить ошибку/повторяемость, а не называть точность без измерений.

## Сборка
Android APK собирается через GitHub Actions. Целевое устройство разработки: Redmi Note 8, Android 11, 4 ГБ ОЗУ.
